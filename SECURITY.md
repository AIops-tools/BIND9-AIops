# Security

Report vulnerabilities privately through GitHub security advisories when the repository is available. Do not share `rndc` keys or private zone data in public issues.

The tool invokes configured binaries with argument lists, never a shell. It does not accept an agent-provided command or file path. Access to `rndc` is controlled by the operating-system account and the `rndc` key file; keep that file private. Reload, refresh and name-specific cache flush have dry-run and CLI double confirmation. RNDC acceptance is recorded as unknown until the operator verifies the resulting DNS state. Audit records and budget enforcement are bundled locally.
